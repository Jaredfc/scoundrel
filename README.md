# Scoundrel — Solo Dungeon Card Game

A free, ad-free browser implementation of the Scoundrel solitaire card game by Zach Gage & Kurt Bieg, themed as a D&D-style dungeon crawl.

Cards are played on a wooden tavern table atop an ornate game board. Includes one-time tutorial, room layout (potions left, monsters center, weapons right), weapon degradation, and procedural sound effects + looping tavern theme.

**Play it:** [https://jaredfc.github.io/scoundrel/](https://jaredfc.github.io/scoundrel/)

Set up for GitHub Pages from the root of the `main` branch (includes `.nojekyll`).

Upload the self-contained `index.html` (with embedded art and audio) to the root to go live.
