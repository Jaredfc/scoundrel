# Scoundrel — Solo Dungeon Card Game

A free, ad-free browser implementation of the Scoundrel solitaire card game by Zach Gage & Kurt Bieg.

Themed dungeon-crawler cards: monsters, weapons, and health potions. Rooms arrange potions on the left, monsters in the center, and weapons on the right.

**Play it:** [https://jaredfc.github.io/scoundrel/](https://jaredfc.github.io/scoundrel/)

Set up for GitHub Pages from the root of the `main` branch (includes `.nojekyll`).

One-time tutorial on first visit. Survive the 44-card dungeon with 20 health!
